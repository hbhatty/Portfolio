## AI usage heatmap

Started officially tracking on August 20, 2026. Combines work done on Codex and OMP.

## Local development

```bash
npm install
npm run dev
```

The site will be available at [localhost:3000](http://localhost:3000).

The bat icon switches between light and dark themes with a 700 ms reveal and
matching icon pulse. During the reveal, ordinary element transitions are disabled
so heatmap cells do not animate their colours and borders at the same time.
Normal hover transitions resume afterwards. Reduced-motion preferences skip the reveal.
